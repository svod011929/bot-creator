# События кликера

Stage 7, 11 ноября 2026. Продолжение точного Stage 6 от `472cc14`. На сервер не установлено.

## Игроку

Открыть **🎉 События** в меню кликера или **События и значки** в приключении. Видны опубликованные
события, включая будущие и завершённые; черновики скрыты. У каждого есть история, срок, цели и награда.
Участие начинается кнопкой **Участвовать**. Действия до вступления не засчитываются.

| Цель | Что засчитывается |
| --- | --- |
| Клики | Успешные клики после вступления до конца последнего дня |
| Экспедиции | Маршруты, начатые после вступления, чей результат получен до окончания события |
| Разные маршруты | Различные маршруты среди таких экспедиций; повтор не даёт новый тип |

Нужно выполнить все включённые цели. После обновления карточки появится **Забрать XP и значок**.
Награда выдаётся один раз. XP входит в игровой опыт, навыки и рейтинг месяца получения.
Денежный баланс, сила клика, реферальные начисления и вывод работают по прежним правилам.

Дата начала и дата конца включены. Игровой день — Москва, UTC+3. Активность перестаёт учитываться в 00:00
после последнего дня. Если цели выполнены вовремя, забрать награду можно ещё **7 суток**;
в момент указанного крайнего срока получение закрывается. Невыполненные цели за эти семь дней не дополняются.

В **Мои значки** хранятся полученные награды. **Первые победители** показывает первые десять получений,
по времени выдачи, затем по ID при совпадении. Это не рейтинг скорости выполнения целей.
До появления события доступны прежние миссии и экспедиции.

## Владельцу

В креаторе: **📚 Контент ботов → кликер → Создать**. Раздел также доступен из карточки бота.
Редактор событий расположен в креаторе. Форму можно отложить, продолжить после перезапуска и исправить по полям.

| Поле | Допустимое значение |
| --- | --- |
| Название / описание | 1–80 / 1–900 символов |
| Начало | Сегодня или дата в течение следующего года |
| Срок | 1–30 календарных дней |
| Клики | 0–100000 |
| Экспедиции | 0–1000 |
| Разные маршруты | 0–4 |
| Награда | 1–1000 игрового XP |
| Значок | 1–60 символов, можно с эмодзи |

Ноль отключает цель; хотя бы одна цель обязательна. Сначала сохраняется черновик. Затем доступны
предпросмотр участника и отдельное подтверждение публикации. Предпросмотр не вступает в событие и не выдаёт XP.
Каталог и календарь читаются без запуска дочернего процесса, оплаты хостинга или обращения к провайдерам.

Опубликованное событие резервирует даты: в один день допускается одно событие, включая находящееся на паузе.
Несколько будущих событий с непересекающимися сроками можно запланировать заранее.
После публикации условия закреплены. Для изменений создаётся редактируемая копия с началом «сегодня».
Повторное нажатие «Копия» возвращает тот же незавершённый черновик копии.
Старый черновик с прошедшим началом требует новой даты перед публикацией.

Пауза закрывает вступление новым игрокам. Уже вступившие могут выполнять условия до конца срока и получать
награду по тем же правилам. Возобновить событие после конца нельзя; для нового запуска нужна копия.
В карточке владельца есть число участников и получений. Публикация не запускает процесс и не отправляет рассылки.

Пример **Неделя разведчика**: 25 новых кликов, одна новая завершённая экспедиция, 40 XP и значок
**🧭 Разведчик недели**, срок семь дней. Он создаётся только как скрытый черновик.

## Хранение и совместимость

| Новая таблица | Назначение |
| --- | --- |
| `clicker_events` | Условия, расписание, статус, редакция и связь копии |
| `clicker_event_players` | Вступление, точки отсчёта, снимок единственной награды |
| `clicker_event_audit` | Действие владельца и номер редакции |

Четыре явно созданных индекса: расписание, единственная черновая копия, порядок получений и личные значки.
Первичные ключи и уникальная редакция аудита создают штатные индексы SQLite.
Старые таблицы и столбцы не перестраиваются.

На вступлении фиксируются текущие дневные клики и максимальный ID собственной экспедиции.
Это исключает старые действия и уже начатый маршрут даже при совпадении секунд времени.
Прогресс читается из `clicker_counters` и `clicker_expeditions`, с отсечением по сроку.
Дополнительных записей событий на каждый клик нет. Индексы игровых фактов существовали в Stage 6.

Награда использует прежний XP-журнал с совместимым типом `mission` и отдельным уникальным ключом
`event:<событие>:<игрок>`. В интерфейсе это «Событие», в аналитике — отдельный шаг.
Запись XP, профиль, рейтинг и квитанция значка находятся в одной транзакции `BEGIN IMMEDIATE`.
Повторные и конкурентные получения не дают второй награды; сбой откатывает всё действие.
Публикация и резервирование дат также сериализованы. Проверки редакции защищают от устаревшей формы.

Таблицы событий создаются при запуске кликера. У других шаблонов их нет.
В креаторе просмотр не создаёт схему; явная подготовка создаёт только каталог и скрытый пример.
Форма использует прежнюю `creator_content_forms` с кодом шаблона `clicker`.
Проверяются актуальное владение, метаданные, конфиг, пути и отсутствие симлинков, как в остальных каталогах.
Ввод ключей доступа отклоняется; импортированный ключ скрывается до сокращения текста.

Локальная аналитика `event_join` и `event_claim` записывается только в контексте собственного личного чата;
владелец исключён. Сбой наблюдения не отменяет игру. Общие гейты подписки и выводов сохранены.

## Перед установкой

Локальные проверки перечислены в `STAGE7_CHANGES.md`. Перед production нужен обычный review и резервная копия
актуальных данных. Устанавливается код без замены БД. После запуска проверить подготовку, предпросмотр и одну
тестовую публикацию на отдельном боте. Живую доставку и состояние демо этот архив не подтверждает.
